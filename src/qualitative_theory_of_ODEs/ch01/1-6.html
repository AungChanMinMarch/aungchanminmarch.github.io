Let $D$ represent a region in $(n + 1)$-dimensional space; this is a set of points with the property that given any point $(t_{0}, \eta)$ in $D$, the interior of the $(n + 1)$-dimensional "box" $$B= \{ (t, y) | \abs{t - t_0} < a, |y - \eta| < b \}$$ for a, b > 0 and sufficiently small, lie entirely in $D$. (We note that if we use the Euclidean norm $\norm{y - \eta} < b$ then the set $$C = \{ (t,y)| \abs{t - t_{0}} < a , \norm{y - \eta} < b \}$$

We define the Zero vector $\vector{O}$ (the origin of $E_n$ by $\vector{O}=(0,...,0)$ and for any point $y \in E_n$ we define $c\vector{y}$, where c is any real or complex number, by the relation $$c \vector{y} = (cy_1, cy_2,..., cy_n)$$ If $\vector{y}$ and $\vector{z}$ are two vectors in $E_n$, we define their sum $\vector{y} + \vector{z}$ to be the vector $$ \vector{y} + \vector{z} = (y_1+z_1, y_2 + z_2, ...,y_n + z_n)$$ and, of course, $\vector{y}-\vector{z} = \vector{y} + (-\vector{z})$. Two vectors $\vector{y}$ and $\vector{z}$ are equal if and only if $y_i = z_i (i=1,2,...,n)$. The Euclidean length of the vector $\vector{y}$ is defined by the relation $$\norm{\vector{y}} = (\abs{y_1}^2 + ... + \abs{y_n}^2)^{\frac{1}{2}} = \bracket{\sum_{i=1}^n \abs{y_i}^2}^{\frac{1}{2}}$$
