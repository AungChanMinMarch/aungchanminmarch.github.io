$T_1$-SPACES

A topological space $X$ is a $T_1$-space iff it satisfies the following axiom:

[$T_1$] Given any pair of distinct points $a, b \in X$, each belongs to an open set which does not contain the other.

In other words, there exist open sets $G$ and $H$ such that $a \in G$, $b \notin G$ and $b \in H, a \notin H$.

The open sets G and H are not necessarily disjoint.

Theorem 10.1
A topological space $X$ is a $T_{1}$-space if and only if every singleton subset $\{p \}$ of $X$ is closed.

Since finite unions of closed sets are closed, the above theorem implies:

Corollary 10.2

$(X, \topologyTau)$ is a $T_{1}$-space if and only if $\topologyTau$ contains the cofinite topology on X.

Example 1.1: Every metric space $X$ is a $T_1$ space, since we proved that finite subsets of $X$ are closed.

Example 1.2: Consider the topology $\topologyTau = \{X, \emptyset, \{a\} \}$ on the set $X = \{a, b\}$. Observe that $X$ is the only open set containing $b$, but it also contains $a$. Hence $(X, \topologyTau)$ does not satisfy $[T_{1}]$ i.e. $(X, \topologyTau)$ is not a $T_{1}$ space. Note that the singleton set $\{a\}$ is not closed since its complement $\{a\}^C = \{b\}$ is not open.

Example 1.3: The {% aTag collections.all "4201_5_1" "cofinite topology" "cofinite" %} on $X$ is the coarsest topology on $X$ for which $(X, \topologyTau)$ is a $T_{1}$ space (Corollary 10.2). Hence the cofinite topology is also called the $T_{1}$ topology.
