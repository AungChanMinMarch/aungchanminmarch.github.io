--- title: "9.1 Definitions" ---
  1. A nonempty set $X \subset \R^n$ is a vector space if $\bvec{x} + \bvec{y} \in X$ and $c \bvec{x} \in X$ for all $\bvec{x} \in X, \bvec{y} \in X$ and for all scalars $c$.
  2. If $x_{1},..., x_k \in \R^n$ and $c_{1},..., c_k$ are scalars, the vector $$c_{1} \bvec{x_1} + \cdots + c_k \bvec{x_k}$$ is called a linear combination of $x_1, \cdots, x_k$. If $S \subset \R^n$ and if $E$ is the set of all linear combinations of elements of $S$, we say that $S$ spans $E$, or that $E$ is the span of $S$.
  3. A set consisting of vectors $\bvec{x_1}, ..., \bvec{x_k}$ is said to be independent if the relation $c_1 \bvec{x_1} + \cdots + c_k \bvec{x_k} = \bvec{0}$ implies that $c_1 = \cdots = c_k =0$. Otherwise $\{\bvec{x_1}, \cdots, \bvec{x_k} \}$ is said to be dependent.
  4. If a vector space $X$ contains an independent set of $r$ vectors but contains no independent set of $r+1$ vectors, we say that $X$ has dimension $r$, and write: $\dim X = r$.

    The set consisting of $\bvec{0}$ alone is a vector space; its dimension is $0$.

  5. An independent subset of a vector space $X$ which spans $X$ is called a basis of $X$.

    Observe that if $B = \{ \bvec{x_1} ,...,\bvec{x_r} \}$ is a basis of $X$, then every $\bvec{x} \in X$ has a unique representation of the form $\bvec{x} = \sum c_{j} x_{j}$. Such a representation exists since $B$ spans $X$, and it is unique since $B$ is independent. The numbers $c_{1} ,...,c_r$ are called the coordinates of $\bvec{x}$ with respect to the basis $B$.

    The most familiar example of a basis is the set $\{ \bvec{e_1}, \cdots, \bvec{e_n} \}$ where $\bvec{e_j}$ is the vector in $\R^{n}$ whose jth coordinate is $1$ and whose other coordinates are all $0$. If $\bvec{x} \in \R^n$, $\bvec{x} = (x_1, \cdots, x_n)$, then $\bvec{x} = \sum x_{i} \bvec{e_i}$. We shall call $\{ \bvec{e_1}, \cdots, \bvec{e_n} \}$ the standard basis of $\R^{n}$.

Show that every span in $\R^n$ is a vector space.
1st Method

Let $S \subset \R^n$ and $E=\{ c_1 \bvec{x_1} + \cdots + c_k \bvec{x_k} | \bvec{x_1}, \cdots, \bvec{x_k} \in S, c_1, \cdots, c_k \text{ are scalars.} \}$.

Since $\bvec{x_1}, \cdots, \bvec{x_k} \in S$, $\bvec{x_1}, \cdots, \bvec{x_k} \in \R^n$ and hence $\bvec{x_1}, \cdots, \bvec{x_k} \in E$.

Thus $E \subset R^n$ and $E \neq \emptyset$.

Take any two vectors $c_1 \bvec{x_1} + \cdots + c_k \bvec{x_k}$ and $a_1 \bvec{x_1} + \cdots + a_k \bvec{x_k} \in E$, where $c_1, \cdots, c_k, a_1, \cdots, a_k$ are scalars.

\begin{align} \text{Then }&(c_1 \bvec{x_1} + \cdots + c_k \bvec{x_k}) + (a_1 \bvec{x_1} + \cdots + a_k \bvec{x_k}) \\ = &(c_1 +a_1) \bvec{x_1} + \cdots + (c_k+a_k) \bvec{x_k}\\ \in &E \end{align} since $(c_1 +a_1) + \cdots + (c_k+a_k) $ are scalars.

\begin{align} \text{Also }&a(c_1 \bvec{x_1} + \cdots + c_k \bvec{x_k}) \\ = &a(c_1) \bvec{x_1} + \cdots + a(c_k) \bvec{x_k}\\ = & (ac_1) \bvec{x_1} + \cdots + (ac_k) \bvec{x_k}\\ \in &E \\ \end{align} since $(ac_1) + \cdots + (ac_k) $ are scalars.

Hence $E$ is a vector space.

Show that no independent set in $\R^n$ contains the null vectors.

OR

Prove that any set of vectors containing the null vector is dependent.

Let X be a vector space over any field of scalars.

Now consider a set of vectors $\{\bvec{v_1}, \cdots, \bvec{v_n} \}$ \subset X$ where $\bvec{v_1} = \bvec{0}$.

Now, for any scalars $a_1,\cdots, a_n$, consider

\begin{align} a_1 \bvec{a_1} + a_2 \bvec{v_2} + \cdots + an \bvec{v_n} &= \bvec{0} \\ \bvec{0} + a_2 \bvec{v_2} + \cdots + an \bvec{v_n} &= \bvec{0} \\ a_2 \bvec{v_2} + \cdots + an \bvec{v_n} &= \bvec{0} \\ \end{align}

If $\{ v_2, \cdots, v_n \}$ is independent, then $a_2 = \cdots = a_n = 0$.

But we cannot conclude that $a_1 = 0$.

Thus we get at least non-zero scalar $a_1$ such that $a_1 \bvec{a_1} + a_2 \bvec{v_2} + \cdots + an \bvec{v_n} = \bvec{0}$

Thus, by definition, the given set of vectors containing the null vector is dependent.
