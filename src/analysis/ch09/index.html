Preliminary

Definitions of $\R, \R^k$, vector addtion, scalar multiplication, scalar product and norm

$\R$ the set of all real numbers
$\R^k$ the set of all ordered k-tuples $\bvec{x} = (x_1, x_2, \cdots, x_n)$, where $x_1,...,x_n$ are real numbers,
vector addition $\bvec{x} + \bvec{y} = (x_1+y_1, ..., x_n + y_n )$
scalar multiplication $\alpha \bvec{x} = (\alpha x_1, ..., \alpha x_n)$
scalar product $\bvec{x} \scalarProduct \bvec{y} = \sum_{i=1}^{k} x_i y_i$
Norm $ \norm{x} = (\bvec{x} \scalarProduct \bvec{x})^{\frac{1}{2}}= \bracket{\sum_{1}^{k} x_i^2}^{\frac{1}{2}}$

Show that $(\R^k, \norm{\cdot})$ is a metric space.

In $\R^k$, $d(x, y) = \norm{x - y} = \bracket{\sum_{i=1}^{k} (x_i - y_i)^2}^{\frac{1}{2}}$

(i) Clearly,$ \norm{x - y}^2 = \sum_{i=1}^{k} (x_i - y_i)^2 \geq 0$. \begin{array}{rrl} \norm{x - y}^2 = 0 \iff & \sum_{i=1}^{k} (x_i - y_i)^2 &= 0 \\ \iff & (x_i - y_i)^2 &= 0, 1 \leq i \leq k \\ \iff & x_i &= y_i, 1 \leq i \leq k \\ \iff & (x_1, ..., x_k) &= (y_1, ..., y_k) \\ \iff & x &=y \end{array}

(ii) \begin{align} \norm{x -y}^2 &= \sum_{i=1}^{k} (x_i - y_i)^2 \\ &= \sum_{i=1}^{k} (y_i - x_i)^2 \\ &= \norm{y - x}^2 \\ d(x,y) &= d(y, x) \end{align}

By {% a 1.37 %}, $$\norm{x - y} = \norm{x - z + z -y} \leq \norm{x - z} + \norm{z - y}$$ Thus $d(x,y) \leq d(x, z) + d(z, y)$.

Define vector space, vectors, real vector space, complex vector space, null vector, vector subspace, proper vector subspace.

Vector Space

A vector space is a set $X$ along with two operations: vector addition and scalar multiplication. If $ \bvec{x}, \bvec{y}, \bvec{z} $ are vectors in $X$ and $\alpha, \beta$ are scalars, then the following properties must hold:

  • Commutativity of addition: $ \bvec{x} + \bvec{y} = \bvec{y} + \bvec{x} $
  • Associativity of addition: $ \bvec{x} + (\bvec{y} + \bvec{z}) = (\bvec{x} + \bvec{y}) + \bvec{z} $
  • Identity element of addition: There exists an element $ \bvec{0} \in V $ such that $ \bvec{x} + \bvec{0} = \bvec{x} $ for all $ \bvec{x} \in V $
  • Inverse elements of addition: For each $ \bvec{x} \in V $, there exists an element $ -\bvec{x} \in V $ such that $ \bvec{x} + (-\bvec{x}) = \bvec{0} $
  • Compatibility of scalar multiplication with field multiplication: $ \alpha (\beta \bvec{x}) = (\alpha \beta) \bvec{x} $
  • Distributivity of scalar multiplication with respect to field addition: $ (\alpha + \beta) \bvec{x} = \alpha \bvec{x} + \beta \bvec{x} $
  • Distributivity of scalar multiplication with respect to vector addition: $ \alpha (\bvec{x} + \bvec{y}) = \alpha \bvec{x} + \alpha \bvec{y} $
  • Identity element of scalar multiplication: $ 1 \bvec{x} = \bvec{x} $, where 1 is the multiplicative identity in the field of scalars

Elements of $X$ are called vectors.

If $\K = \R$, then $X$ is called a real vector space.

If $\K = \C$, then $X$ is called a complex vector space.

The zero element $\bvec{0}$ is called the null vector.

A subset $E$ of a vector space $X$ is called a vector subspace if every $\alpha, \beta \in \K$ and $\bvec{x}, \bvec{y} \in E$, the vector $\alpha \bvec{x}$, $\alpha \bvec{y} \in E$.

    Note that
  1. Every vector space is a subspace of itself.
  2. $E$ is a proper subspace of $X$ if $E$ is a subspace of $X$ and $E \neq X$.
  3. A subspace of a vector space is a vector space itself.

Note that these definitions are not from Rudin Analysis.
