--- title: theorem 1.37 ---

{{ title }}

Suppose $\vector{x}, \vector{y}, \vector{z} \in \R^k$, and $\alpha$ is real. Then
  1. $\norm{\vector{x}} \geq 0;$
  2. $\norm{\vector{x}} = 0 \text{ if and only if } \vector{x} = \vector{0}$
  3. $\norm{\alpha \vector{x}} = \abs{\alpha} \norm{\vector{x}}$
  4. $\norm{\vector{x} \scalarProduct \vector{y}} \leq \norm{\vector{x}} \norm{\vector{y}}$
  5. $\norm{\vector{x} + \vector{y}} \leq \norm{\vector{x}} + \norm{\vector{y}}$
  6. $\norm{\vector{x} - \vector{z}} \leq \norm{\vector{x} -\vector{y}} + \norm{\vector{y} - \vector{z}}$
