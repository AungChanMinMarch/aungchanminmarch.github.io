--- title: theorem 1.37 ---

{{ title }}

Suppose $\bvec{x}, \bvec{y}, \bvec{z} \in \R^k$, and $\alpha$ is real. Then
  1. $\norm{\bvec{x}} \geq 0;$
  2. $\norm{\bvec{x}} = 0 \text{ if and only if } \bvec{x} = \bvec{0}$
  3. $\norm{\alpha \bvec{x}} = \abs{\alpha} \norm{\bvec{x}}$
  4. $\norm{\bvec{x} \scalarProduct \bvec{y}} \leq \norm{\bvec{x}} \norm{\bvec{y}}$
  5. $\norm{\bvec{x} + \bvec{y}} \leq \norm{\bvec{x}} + \norm{\bvec{y}}$
  6. $\norm{\bvec{x} - \bvec{z}} \leq \norm{\bvec{x} -\bvec{y}} + \norm{\bvec{y} - \bvec{z}}$
